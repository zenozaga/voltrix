Introduce the brand new `@voltrix/websocket` package, delivering a high-performance, programmatic-first and decorator-driven real-time WebSocket suite natively optimized for `uWebSockets.js` and `@voltrix/server`. Includes native C++ local pub/sub, distributed Redis pub/sub room synchronizers, heap-allocated asynchronous upgrade request safety, and onion-style middleware event pipelines.
